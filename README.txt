CARA MENJALANKAN WEBSITE ULANG TAHUN

1. Ekstrak ZIP ini.
2. Buka folder website-ulang-tahun-romantis di VS Code.
3. Buka script.js, ganti const namaPasangan = "My Love" dengan nama pasangan.
4. Masukkan foto ke folder images dengan nama foto-1.jpg, foto-2.jpg, foto-3.jpg.
5. (Opsional) Masukkan musik MP3 ke folder music dan beri nama lagu.mp3.
6. Install extension Live Server di VS Code.
7. Klik kanan index.html > Open with Live Server.

CATATAN FOTO:
- Gunakan file JPG/JPEG dan nama persis seperti di atas.
- Untuk foto lain, edit src pada tag img di index.html.
- Jika foto tidak tampil, periksa ejaan nama file dan foldernya.

CATATAN MUSIK:
- File harus bernama music/lagu.mp3.
- Browser tidak mengizinkan autoplay bersuara sebelum ada interaksi pengguna.
- Klik tombol Putar musik di kanan atas halaman.
